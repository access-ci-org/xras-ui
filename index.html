Publications alerts

Every fetch in the publications feature reports failures through addErrorAtom, which renders as a dismissable alert. The route overrides below point at paths this dev server has nothing behind, so the alerts show up with no Rails backend running. Two appear on load — the publication search and the filter list — and two more are there to trigger by hand:

  • Update your publications — fails the dismiss POST.
  • Add a New Publication — fails the form load, so the modal shows its alert at the top instead of spinning forever.

Each of the four is a real 404 in the network tab, which is what makes response.ok false. Worth knowing if you point these somewhere else: Vite serves this page for any unmatched path that accepts HTML, so a route with no Accept: application/json on its fetch would come back 200 with this document as the body, and fail one step later in response.json().
